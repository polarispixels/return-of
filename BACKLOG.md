# Backlog

Committed work lives in [GitHub Issues](https://github.com/polarispixels/return-of/issues), each with one MoSCoW, one effort, and one type label. This file holds loose ideas that are not issues yet. When an idea firms up, file it and delete it here.

## Ideas

- More styles for content types not yet considered (Scandinavian for calm reading pages, New Wave for title pages only).
- A style switcher on the docs page to preview a page in each theme.
- A shared header and footer once copying them between pages gets tedious (likely the moment to add a small static site generator).
- Private or unlisted pages for personal notes and positions.
- A `polarispixels.com` subdomain pointing at the site.
- Multimedia pages: embedded video, audio notes, interactive calculators.
